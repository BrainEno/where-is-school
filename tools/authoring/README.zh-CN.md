# 游戏内剧情作者版

作者版是独立的游戏副本。它加载同一间教室、同一个 NPC 和同一套对白面板。只有明确启动作者版才有「剧情编辑」入口；普通游戏没有入口和草稿代码。作者版的存档、设置和草稿都不与普通版共用。

## 桌面启动

安装仓库 `.godot-version` 指定的标准版 Godot 和 Python 3。首次准备需要导入资源。若 Linux 上新输入的汉字缺字，请安装 Noto Sans CJK 等系统字体。

```sh
python3 tools/authoring_build.py --godot godot --output builds/author-project
```

命令复制 Git 跟踪的游戏资源到新的空目录，不改普通项目或已发布对白。之后可直接 `godot --path builds/author-project`。新版本用另一个空目录准备，草稿从同一个作者版数据目录读取。请勿同时启动两个作者版实例编辑同一份草稿。

## 编辑、试走、导出

1. 进入游戏，对教室的坐姿同学发起对话。`prologue / student / st_reciting` 有原来的两个选项。点击「剧情编辑」，会停在当前对白；没在对白中也可按章、会话和节点选择。
2. 编辑正文，或从「文案」选择原选项。在 iPhone 点「编辑这个字段」，用系统输入法在游戏旁的文本窗口输入，点「应用」。原版游戏的世界暂停，旁边的对白是**草稿预览**；「看原文／看草稿」可切换。作者稿当前只编辑简体中文数据，但输入可用其他语言字符。
3. 在无条件、无检定、无选项的普通节点选「插句」，选择该会话已有的说话人；保存后新句自动接回原去向。在无条件的普通选择点选「加选项」，可直接接已有节点，或增加一条回应，再接已有节点或结束。不允许新增节点循环返回这个选择点，不新增条件、检定、标记、世界事件或 NPC 绑定。
4. 点「试走」从所选会话的开头走当前预览（草稿或原文）。可选新选项、读到新增回应，再沿原路线读下去。试玩使用现在的旗标和知识副本，不写真实存档、已读、任务或背包；不是整个世界的分支。点「返回编辑」后可继续调整。「回游戏」回到原对白，不会把草稿热替换进原存档。
5. 已应用文案自动保存；结构编辑要点「保存新增」才能进试走/导出，未完成表单会另存到本机以便恢复。iPhone 系统编辑窗口里的输入需要先点「应用」；尚未应用时强退不保证恢复。等保存状态不再显示「正在保存」再退出。新游戏不清空草稿；按两次「清空」才重置当前草稿。作重要修改前可先导出备份。
6. 点「导出 JSON」。桌面选择一个新的 `.json` 文件（不覆盖已有文件）。iPhone 在系统「文件」窗口选择「在我的 iPhone」也可离线保存；仅复制这一个 JSON，不共享存档目录。取消会保留草稿和「未导出」状态。没有自动同步。

## 电脑预检作者稿

```sh
python3 tools/review_author_draft.py /path/to/where-is-school-dialogue-draft.json \
  --godot godot --output builds/author-review
```

不指定 `--output` 只预检。指定的新空目录会得到候选中英文 JSON、`preview.diff` 和 `pending_en.json`。按原字段/原后续检查冲突；同一字段在别处改过、锚点不再存在、去向无效时拒绝，不覆盖。英文副本复用现有译文；待译处不当作最终译文。确认差异、完成待译、跑剧情校验／中英结构测试和字库检查后，才按 [故事文档流程](../../docs/STORY_DOCS.zh-CN.md) 审核候选文件。工具不会修改仓库对白或 Google Docs。

## iPhone 构建与验收

作者版 Bundle ID：`io.github.braineno.whereisschool.authoring`，和普通版可并存。CI 的 macOS 测试只编译 UIKit 组件并校验无签名归档（不是可安装 IPA）。**CI 通过后**才在受信任的 macOS + Xcode 环境签名；使用明确匹配该 Bundle ID 的 Development 或 Ad Hoc 描述文件，并包含目标设备。项目已有 `sign_ipa.py` 的三个受保护输入仍从私密环境提供；不要用聊天、PR 或公开构件传签名材料及设备描述文件。公开 `build-ios.yml` 的保护规则不变，不用它发作者版私密 IPA。

```sh
python3 tools/macos/ios/sign_ipa.py --authoring --distribution development \
  --build 1 --output builds/author-ios-signed
```

`--build` 使用实际递增值；可换成 `--distribution ad-hoc` 并配置对应签名。签出的结果先核对 `BUILD.json` 的 `head`、`bundle_id`、`modified_sources` 与 `sha256`，只私下交付 `.ipa`。模拟器 `.app` 和无签名 `.xcarchive` 都不能当作手机安装包。

实体机核对：飞行模式进入教室；两种横向握持；拼音／注音候选、在句中选区替换、换行、粘贴、收键盘；选新增选项后接回旧线路；「应用」并保存后强退重开；「文件」选本机目录保存、取消及在电脑运行预检；退出编辑后原游戏与方向控件正常。自动测试的安全区和无签名归档不能代替这些项。

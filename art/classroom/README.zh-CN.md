# 教室视觉切片：源文件与色彩系统

*English: [README.md](README.md)*

本目录存放教室绘画风格的**源文件**。目录内有 `.gdignore`，Godot 不会导入它；`export_presets.cfg`
也已把 `art/*` 排除在导出之外。

- `paint_classroom_textures.py` 负责绘制 `assets/materials/classroom/textures/` 下的全部 PNG，
  并为每张图写好 `.import` 配置文件。运行环境为 Pillow 11.3.0 + NumPy 2.2.6，重跑得到的文件逐字节一致：
  `python3 art/classroom/paint_classroom_textures.py`。

教室里没有任何静态背景图。墙、地板、黑板、窗户仍然是原灰盒的 3D 几何体。
绘画以贴图形式画在一组四边形上，这些四边形贴在墙体和地板前方 4 mm 处，
并且挂在对应墙体节点下面，因此相机遮挡淡出时会跟着各自的墙一起淡出。

## 识别度：这间教室为什么是“这间”

教室的识别度来自房间本身：青色墙裙、地面上朱红色的讲台区、牛血红的黑板框、
写不成字的布横幅，以及从窗外照进来、本不该出现的橙色光。
我们没有加全屏“油画”滤镜。材质都是普通的 `StandardMaterial3D`（toon 漫反射、无高光），
所以风格体现在画了什么，而不在着色器特效上。教室不依赖 `assets/shaders/**`。

### 层级规则

1. **大面保持安静**：墙和地面的平均色彩度不超过 0.20（平均 sRGB 颜色的最大分量减最小分量）。
2. **重要物件必须从背景里分离出来**：明度差或色彩度差至少达到 0.15。
   对照组包括：黑板对墙、书包对地面、窗对墙、三角尺和点名册对讲桌面、门框对后墙。
3. **重复家具不抢戏**：12 把椅子的色彩度至少比书包低 0.15。
4. **墨线只画边，不当纹理用**：墨线只出现在轮廓、接缝和少量涂鸦上，
   不覆盖可行走地面，也不覆盖可交互物。

`tests/classroom_visual_slice_test.gd` 会在实际发布的贴图上测量以上四条规则。

## 图形标记，每一处都有理由

- **前墙**：黑板背后的剪纸式阴影、蹭到墙上的粉笔灰，以及门边有人画了一半就放弃的铅笔身高刻度。
- **窗墙**：两扇窗周围溢出的杏橙光、画出来的窗洞侧面，以及后窗下方的粉笔计数划痕。
- **东墙**：撕掉通知后留下的浅色印子和残余胶带，还有一扇哪儿也通不到的粉笔小门。
- **后墙**：真门外面多描了一圈潦草的门框，以及一块彩色粉笔画的旧黑板报
  （叶子、鱼骨、小花，没有可读的字）。
- **前黑板**：板擦弧线下残留的标题和日期栏痕迹，与检视文本一致
  （*LAST TERM — REVISION*，以及一个三周前的日期）。这些字迹刻意保持不可辨认，因此黑板不需要本地化。
- **横幅**：笔势像字，但在两种语言里都拼不出任何内容。

## 检视文本 → 场景

| 文本描述 | 场景中的对应 |
|---|---|
| 黑板擦过又没擦干净；粉笔槽里有一截断粉笔和一个夹子 | `Board/Face` 贴图、`ChalkBrokenEnd`、`Clip`、粉笔槽上的粉笔灰 |
| 两块玻璃，一块裂了、用胶带补过；窗外是湿水泥地、矮墙、一排垃圾桶；傍晚的光 | `WindowGlass0`（裂纹 + 胶带）、`window_view.png` |
| 三角尺有前臂长，清漆发白，裂开的角用已经变褐的胶带补过，补过的角朝向教室 | `set_square.tscn` 现在平放（0.55 × 0.42 m；原棱柱的尺寸轴写反了），`TapeRepair` 改为褐色胶带，并加了墨线刻度 |
| 自己的课桌上有被刮掉的名字、撕了一半的贴纸、前沿一道磨出的凹槽 | `Furniture/DeskB2/DeskMarks` 贴花 |
| 讲桌上有塑料封皮的点名册、订书机、装粉笔的杯子；椅子斜着推进去；比其他桌子整洁 | `Register` 及标签、`Stapler`、插着三支粉笔的 `Mug`、`Papers`、新增的 `Chair` |

## 未改动的部分

房间尺寸、墙体、门洞、课桌网格、出生点、全部可交互物及其位置，
以及 `Sun` / `WorldEnvironment` 节点都保持原样。
本次没有新增任何碰撞体，所以运行时烘焙导航网格看到的实体与原来完全相同。

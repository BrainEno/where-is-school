# 器材归还线——户外场景交互扩展

中文阅读本，源文：[README.md](README.md)。

街道、院子、后巷和操场组成一圈可走的路线，不需要把四处均匀摆满。保留长视线和场地中部的空旷。在现有配色上局部使用米白搪瓷、蓝灰铁件和一点赭色。路牌是一道长横、同侧两道长短不一的竖线，再配一个箭头。记号反过来后仍能认出是同一套牌子，不以此新增一扇门，也不解释学校为何如此。

| 地点 | 可读的细节 | 作用 |
| --- | --- | --- |
| 街道 | 学校墙脚的搪瓷归还牌，往前一段有磨亮的回执投口 | 箭头指向住宅区楼梯，右侧两道短竖记进笔记；投口只是短检视，不添新任务。 |
| 住宅区 | 巷口的小号搪瓷牌；换过板条的长椅下有一撮扫拢的碎屑 | 引向原有通道，也让原有长椅描述在画面中有对应。不增加提示、笔记旗标或目标。 |
| 后巷 | 方向相反的同款牌；塞了木楔的推车导轨 | 单独记下靠左的短竖。木楔说明这里怎么使用，不做成谜题，也不压缩通道。 |
| 操场 | 双面归还板、球场划线盒、栓链的排水塞、棚窗里的同款纸条 | 第一次读板就能知道两条原有退路。划线盒能帮助辨认纸条。龙头不用操作也能离开。 |

归还板不再借用球场地面的检视描述。首次读完两块室外牌和归还板后，在原有器材棚对话里**多一个选项**，不会自动掷骰。划线盒可不看；看过才有一分情境加值。可见的方位感检定分别记录「对上了」与「还分不清」，来源都是实见。没读标牌也能用归还板指路；失败不封门，不算完成原有棚门检查；重访不重掷。不另做背包、任务调度、输入或能力系统。

## 源文件与再生成

资源直接写进原有两套 Python 美术生成器。路标和箭头复用网格，不依赖贴图或字体；没有引入外部图片、模型或音频。用各场景已有的局部材质，装饰网格不加实体碰撞。墙面标牌跟随所属遮挡体淡出，不会悬在墙外。操场公告板沿用原立柱的占地，双面低于角色腰线并向上倾斜，避免跟随镜头里遮住玩家。出生点、出口及物理碰撞均不变。

```sh
python3 tools/build_outdoor_locations.py street residential alley playground
python3 scenes/environment/props/stage_art/source/build_stage_art.py  # 沿用 numpy/Pillow 依赖
python3 scenes/environment/props/playground_art/source/build_playground_art.py
```

两种语言的状态效果和文案位于 `data/{inspections,dialogue}/{en,zh-CN}/`。归还板近景复用 `CameraShot`，资源为 `assets/camera/shots/return_board.tres`。`tests/return_route_test.gd` 通过真实行走、键盘交互和网格点击验证路线，并用同一临界骰点对比有、无加值。`tests/capture_locations.gd -- return-route` 为 Location art capture 提供改动前后的相同机位。请在游玩镜头而不是自由编辑镜头内验收图和文。

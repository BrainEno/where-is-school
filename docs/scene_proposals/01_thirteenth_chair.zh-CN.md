# S1 第十三把椅子

- **状态：** 已立项，未实现。
- **类型：** 一个独立的小地点（教师办公室）加一段谈话场景。
- **来自：** 视觉实验室 C 区（`scenes/dev/visual_experiments/zones/expression_room.gd`）。证据帧见 `docs/screenshots/visual_experiments/*/07_expression_room.jpg` 和 `08_expression_shadow.jpg`。
- **地图位置：** `docs/MAP_PLAN.md` 第 5 节的“教师办公室”（建议新增）：“没有人的权威；纸张”。

## 1. 目标

用一个房间，而不是一个特效，让玩家**身体上**感到制度的压力：十二把椅子朝向一把椅子，一道从高处窄缝射进来的硬光，墙往里倾。房间里的一个细节，即一道“画出来的影子”，和真实的影子指向相反。玩家可以注意到它，也可以错过；可以记住它，也可以不信它。

谈话本身照常进行。房间不解释自己，谈话也不解释房间。

## 2. 故事节拍（候选，待所有者确认）

叙事圣经只规定了 B 的功能，没有规定她何时出场。下面的节拍刻意把谈话对象写成“对面的人”，由所有者从第 8 节的选项中决定。

1. **被叫去。** 主角接到去办公室的要求（来源待定：广播、N、一张纸条）。走廊上的路感可以给出一个**带偏见的**方向判断。
2. **进门。** 先看到房间：长桌，十二把椅子在一侧，一把单独的椅子在另一侧。硬光落在那把椅子上。没有旁白。
3. **坐或不坐。** 第一个选择是姿态，不是对错：坐进第十三把椅子、站着、或者去坐十二把中的一把。选择改变谈话的语气和关系，不锁死任何路线。
4. **谈话。** 内容围绕开场已经建立的事实展开：空白的生物考卷、不见了的课本、木三角尺。对面的人既不证实、也不否定 Q 的说法（叙事圣经对 B 的要求）。
5. **影子。** 玩家在谈话中或谈话后可以检查那把椅子。它的真实影子朝西；地上另有一道画出来的影子朝东，指向光源，这在物理上不可能。细察和推演会给出**互相矛盾**的解读，回声可能“想起”一个说不准的画面。没有哪一种解读被确认。
6. **离开。** 门照常打开。下次回来时，画出来的影子可以不见，也可以换一个方向。这需要一个剧情标记，见第 4 节。

## 3. 玩家动作

| 动作 | 实现方式 | 备注 |
|---|---|---|
| 走进房间、走到桌边 | 现有点击寻路与键盘移动 | 房间的可走区域是一个 `NavigationRegion3D` |
| 选择坐哪里 | 对话选项，`choice_id` 进入 ReadLog | 坐下动作复用 `CharacterVisualAnimation.set_seated()` |
| 检查第十三把椅子、画出的影子、光缝 | 现有 `inspections` 数据加描边（`outline_paths`） | 画出的影子是可检查物，必须能被描边，见第 6 节 |
| 被内心声音打断 | `InnerVoiceDirector` 的被动规则 | 细察、推演、回声、共鸣都适合，但目前只实现了路感 |
| 隐藏检定 | 对话数据里的 `check` 块，`kind: hidden` | 失败给出另一个细节，不挡路 |

## 4. 空间与布局

实验室的房间是 12 × 14 m，高 3.6 m，可以作为起点，但在生产中应该缩小。一个小办公室更压迫，也更省。

- **平面：**
  - 一张长桌，十二把椅子在北侧，一把在南侧，正对光缝；
  - 西墙一扇门，通往走廊；
  - 东墙高处一道带铁栏的窄缝。
- **墙：** 南北两面墙向内倾，顶部收拢约 0.9 m。墙是大面积的单色色块，没有纹理：普鲁士蓝、镉橙，门洞一侧是茜草红。地面是铬绿和土黄两块。
- **光：** 只有一盏 `SpotLight3D`，放在窄缝外，开阴影。房间内不放太阳光（理由见第 6 节）。
- **画出来的东西：**
  - 一道画出的影子，朝向光源；
  - 北墙上一块画出的阳光平行四边形，它来自一扇不存在的窗；
  - 二者都是不投影、不受光的平面。
- **天花板：** 生产镜头是高位三分之四视角，所以照现有教室和实验室的做法，**工作区上方不加顶**（`IMPLEMENTATION_NOTES_LABORATORY.md`：“相机往下看进房间”）。实验室里的单面天花板只是为了在第一人称下挡住天空，生产中不需要。
- **剧情标记：** `staff_room_visited` 用来记录到过这里，`staff_room_shadow_seen` 用来记录检查过影子。返回时影子是否变化，由第二个标记控制。

## 5. 技术方案（来自实验室）

| 实验室做法 | 生产做法 |
|---|---|
| 运行时用 `SurfaceTool` 生成带顶点色的墙和地面（`collage_kit.gd`） | 改为编辑器阶段生成并保存为网格资源（美术圣经“程序化几何”一节：优先编辑器阶段生成）。顶点色的通道含义写在生成器里 |
| `colour_field.gdshader`：顶点色、明暗交界、竖向笔触 | 先尝试 ADR 0006 的环境表面方案能否覆盖；不能覆盖时，再把这个着色器作为本地点专用材质重写并测试 |
| 画出的影子与阳光：无光照平面 | 同样做法；要放进 `outline_paths`，可点击，可检查 |
| 十三把椅子 | 使用教室现有的椅子模型，不新建资源 |
| 一盏带阴影的聚光灯 | 同样做法；这是本场景唯一带阴影的光 |

## 6. 渲染器注意事项（实测）

- **Compatibility 下单面天花板漏太阳光**（实验室首轮 CI 运行 43799522663）。生产中的处理是房间内不用平行光，只用聚光灯。这样即使将来加顶，也不会漏光。
- **画出的影子不能用 Decal 做。** Compatibility 不画 Decal（`VISUAL_EXPERIMENTS.md` 第 4 节）。叙事依赖的东西只能用实体平面或网格。
- **向内倾的墙与描边：** 描边由 `OutlineOverlay` 按网格轮廓画出。倾斜的墙不是可交互物，不受影响。但画出的影子贴在地上，描边要单独验证在高视角下是否清楚。
- **跟随镜头：** 实验室按第三人称给 C 区的构图是 (偏航 -35°, 俯仰 58°, 距离 9 m)，从西南高处看进房间。生产中用 `CameraRig` 的 `offset` 为本地点单独设定，谈话时可用 `frame_point` 借用一个更近的构图。

## 7. 性能预算

- **实验室实测**（整座开顶实验室，含其他房间）：从 C 区看，Compatibility 1055 次绘制，Forward+ 412 次，Mobile 356 次，9.2 万图元。
- **生产目标**是一个独立小房间，只有一盏阴影灯。绘制次数应**不高于**现有教室在同一渲染器下的数字，开工时用教室作为基准测一次。
- 不用 SubViewport，不用全屏后处理。

## 9. 风险

| 风险 | 缓解 |
|---|---|
| 房间太“艺术”，变成一个风格展示，而不是一场谈话 | 先做谈话，再做房间；色块只用在这一个房间 |
| 画出的影子被当成谜题答案 | 文本只给观察，不给结论；内心声音互相矛盾 |
| 对面的人把 B 简单化（怪物或笑话） | 按叙事圣经的 B 条目审稿；所有者审阅台词 |
| 高视角下画出的影子看不清 | 灰盒阶段就在 `CameraRig` 下截图验证 |

## 1. 三个场景共同遵守的规则

**叙事（来自叙事圣经）**

- **保留不确定性。** 任何一个场景都不能证实世界是梦、模拟、诊断或平行宇宙，也不能把异常归到单一的隐藏原因上。
- **说法、记忆、想象和观察要分开。** 画出来的影子、不肯结束的走廊、变成画的房间，都是玩家**直接观察**到的东西。但游戏不能借它们去证实或否定某个角色的说法。
- **人物功能不变。**
  - Q 不是向导，也不是任务终端。
  - B 是权威与普通人的小气混在一起，不能被简单证实，也不能被简单揭穿。
  - N 不会因为是代课老师就更真诚。
- **椭圆形建筑不出现**在任何一个场景里。这三个场景也都不在开场的生物课之内。
- **失败也是内容。** 检定失败只给出另一个细节，从不挡住必经节拍（`ARCHITECTURE.md` 5c 第 4 条）。
- **新写所有文本。** 不搬用手稿段落。本目录只写节拍、功能和交互，不写成品台词。

**视觉（来自美术圣经“后现代空间语言”一节）**

- 每个场景建立**自己的局部规则**，只在这一个地点使用。不能把它变成全游戏的滤镜。
- 不可能的东西要**在实际游戏镜头里看得清**。交互反馈不能含糊：可检查、可打开、可穿过的东西始终可辨认。
- **不用廉价恐怖手法：** 没有红字墙、随机血迹、无意义的污渍或警示牌。

**技术（来自实验室的实测与架构文档）**

- **渲染器：** 生产渲染器是 Forward+（ADR 0001）。实验室三种渲染器都测过，结论在 `VISUAL_EXPERIMENTS.md` 第 4、5 节，Compatibility 只作为兜底参考。
- **镜头：** 生产镜头仍是 `CameraRig`，每个地点配一个高位三分之四视角（默认偏移 (3.4, 6.4, 3.4)）。实验室现在用第三人称跟随镜头，并按房间给出构图。它的作用是预览这些空间在跟随镜头下的样子，**不替代** `CameraRig`。
- **地点结构：** 每个场景都是 `LocationHost` 事务能加载的普通地点（`ARCHITECTURE.md` 5h），有一个 `NavigationRegion3D`，出生点叫 `From<来源>`，并登记在 `data/story/locations.json`。不需要传送门系统。
- **文本：** 文本放在 `data/dialogue/<语言>/` 和 `data/inspections/<语言>/`，中英双语；检定写在对话数据里，不写在脚本里。
- **代码：** 实验室代码**不直接搬进生产**。要用的技术在生产侧重写，并配测试；实验室保持原样，作为参照。
- **资源：** 遵守 ADR 0007 的仓库体积预算；外部或生成的资源都记入 `docs/ASSET_PROVENANCE.md`。

## 2. 建议的制作顺序

| 顺序 | 场景 | 理由 |
|---|---|---|
| 1 | **S2 2-3 室** | 技术最成熟：一个触发器、一次瞬移、MultiMesh 门、一档雾。唯一已实现的内心声音“路感”正好是它的主角。它也能顺带完成 `MAP_PLAN` 阶段 2 计划中的楼上走廊。 |
| 2 | **S1 第十三把椅子** | 渲染最便宜（一盏灯，顶点色）。但它取决于 B（或另一位谈话者）怎样第一次出场，这一点要所有者先定。 |
| 3 | **S3 走进画里** | 效果最强，工程风险也最大：要碰全屏渲染、点击寻路和 UI 层级，而且需要一份新的 ADR（0008）。它与 ADR 0006 的关系也要先说清（见 S3 文档）。 |

三个场景互不依赖，可以由不同代理并行推进。上面的顺序只是在资源有限时的建议。

## 3. 需要所有者决定的事项（汇总）

各场景文档的最后一节列出了全部问题。这里只汇总会挡住开工的几项：

1. **S1：** 谁坐在桌子对面？B 第一次出场、N 代替，还是只有空椅子和内心声音？
2. **S1：** 这场谈话在章节中的位置：自由活动之后，还是某次回校之后？
3. **S2：** “2-3”是不是主角的班级？叙事圣经没有定班号，实验室里只是一个占位门牌。
4. **S2：** 楼上走廊放在哪里，从哪里进入？`MAP_PLAN` 阶段 2 的楼梯间还没建。
5. **S3：** 放在哪个房间？建议放在已有的独立地点“实验室”（`scenes/locations/laboratory/`），对应美术圣经里的“拥有自己媒介的实验室”。
6. **S3：** “变成画”要不要成为一种固定语法（例如总是对应“被讲述或被回忆的空间”）？固定下来容易变成解释，所以本文建议不固定。
7. **S3：** 是否批准为媒介切换另立 ADR 0008？它涉及 ADR 0006 没有采纳的屏幕空间后处理。

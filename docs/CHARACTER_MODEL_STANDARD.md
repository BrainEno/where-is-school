# 人物 3D 模型的行业标准，与这个仓库的执行方案

适用对象：运行期角色（主角、Q、代课老师 N、B）。文档描述的是**可以测量的标准**，
每一条都对应一个可以跑的命令或一次可以看的渲染，不是形容词。

## 0. 结论先行：业余感从哪里来

对一个已经通过比例检查的角色，业余感几乎从来不是"比例不对"，而是下面五件事：

| # | 症状 | 为什么一眼就泄气 | 本仓库的判据 |
|---|---|---|---|
| 1 | **贴上去的零件** | 眼睛是球+涂上去的眼线，嘴唇是浮在皮肤上的薄壳，鼻孔是穿过鼻腔的同一张内壁。转折处没有厚度，边缘是直切的锯齿轮廓 | 每个面部特征都必须是皮肤表面的一部分，或者有真实的厚度与转折 |
| 2 | **形体不承载情绪** | 一条直线眉、平嘴角、对称到没有取舍。胆怯是"没有表达的默认脸" | 静止姿态里必须有明确的肌肉状态（眉、睑、嘴角、下颌） |
| 3 | **脸是死的** | 没有眨眼、没有眉眼层次。人眼对"不眨眼的脸"极其敏感 | 角色必须能眨眼；静止表情由模型自带的形状驱动 |
| 4 | **剪影/头发没有剪裁** | 钟形发壳：没有分缝、没有发际线、发绺是平贴的色块；侧面是个包 | 有分缝、有发际线、发绺有厚度与长短差别 |
| 5 | **材质语言不统一** | 皮肤无高光、头发被当成哑光布料 | 每种材质有明确的反射行为：皮肤弱高光、头发各向异性、织物纯漫反射 |

极乐迪斯科的舞台模型本身是低模的、黏土感的，它不"业余"是因为这五条**自洽**：
剪影强烈、色彩成块、姿态和脸都带着人物。自洽比精度更重要。

## 1. 可测量的解剖门槛（头部）

以颏下点(0)到颅顶(1)为脸高 H，规范区间如下。`tools/character_review/anthropometry.py` 直接测量任一 GLB：

| 指标 | 规范 | 说明 |
|---|---|---|
| 眼线 / H | 0.47–0.53 | 眼睛在头部正中 |
| 鼻底 / H | 0.30–0.36 | 中庭与下庭各占 1/3 |
| 嘴线 / 下庭 | 0.28–0.40 | 鼻底到颏下三等分的上 1/3 |
| 眼宽 / 脸宽 | 0.18–0.22 | 五眼宽 |
| 瞳距 / 眼宽 | 0.85–1.15 | 两眼之间正好一只眼 |
| 脸宽 / 脸高 | 0.55–0.70 | 女性取偏低端更显柔 |
| 下颌宽 / 颅宽 | 0.60–0.82 | 女性 0.62–0.75 |
| 下庭 / H | 0.30–0.37 | 下庭过短会显幼稚 |

N 的实测（改造前）：眼线 0.520、鼻底 0.249、嘴线 0.263、眼宽 0.165、瞳距/眼宽 2.593、
脸宽/脸高 0.623、下颌/颅宽 0.718。**比例基本合规，只有眼睛偏窄** —— 所以她的问题
不在比例，在 §0 的 1–5。这条结论本身很重要：改比例解决不了业余感。

## 2. 执行方案（按投入产出排序）

### A. 恢复面部表情通路（最高性价比）
源文件带 9 个面部形状与 3 个眉毛形状，眨眼只影响 130 个顶点（约 3.6 KiB），
但导入时被整体删除，于是 `expression = {}`、`blink_shapes = []`，她不眨眼、无表情。
做法：导入时只保留驱动静止表情与眨眼所需的形状。这是"死脸"的直接解药。

### B. 让脸本身表达角色（形状与形体，不是加装饰）
- **眼睛**：开睑高度决定"警觉 vs 畏缩"，上睑缘下压（眼睑沉重）；
  眼球缩小、虹膜放大、下睑略平，令眼白露出减少 → 读作紧张而不是空洞。
- **眉**：内侧端上提、外侧端下垂、整体压低 → 忧虑/胆怯；右侧略高于左侧造成不对称。
- **嘴**：嘴角向下，唇线缩短且微抿 → "想说话但没说"。
- **下颌/面颊**：下庭收窄一点、面颊略平，去掉硬朗的方感。
全部用平滑场做，保持顶点数、拓扑、权重不变，闭眼/张嘴的附着面同步跟随。

### C. 再造头发
分缝位置、发际线（避免压在眉上）、发绺的分组与长短、两侧的收拢、
后颈的整洁收边。保留"短发"轮廓但让它看起来是被剪出来的，不是被倒模出来的。

### D. 材质
头发：各向异性高光 + 沿发流方向的明暗条纹；皮肤：弱高光与次表面感的暖阴影。

### E. 验收
`tools/character_review/` 下的渲染四视图 + 特写，与 §1 的测量一起进评审；
`tests/character_geometry_test.py` 覆盖新形状的确定性；模型清单随结构变化更新。

## 3. 不做什么

- 不追写实扫描级皮肤（本作是绘画风，追写实会与场景断裂）。
- 不给运行期模型加骨骼（16 关节是既有契约，改骨架会牵动全部动画）。
- 不用贴图解决造型问题：造型错的地方贴图只会放大它。

## 4. N 的改造记录（geometry revision 3）

执行范围与结果，对应 §2 的 A–D；E 节是验收。

| 项 | 改前 | 改后 | 判据 |
|---|---|---|---|
| 眨眼 | 无（`blink_shapes` 为空，导入时删掉了 15 个形状） | `Eye_Blink_L/R` 保留并接上，2.5–5 s 一次 | 表情形状只花 **56 KiB**（稀疏存储），总文件 1.31 MiB，硬预算 1.5 MiB |
| 静止表情 | 无 | `Brow_Compress` 0.42、`Frown` 0.28、`Mouth_Close` 0.34 | 形状由同一形变派生，眨眼仍落在正确的眼睑上 |
| 眼睛 | 24.3 mm 宽 / 148 mm 脸（5.4 眼宽），上睑是球面的边缘 | 上睑下压 2.2 mm 并加厚 1.5 mm，形成真实褶皱；开睑加宽 | 眼睑可读、虹膜不糊 |
| 眉毛 | 水平、对称 | 内侧抬 3.8 mm、外侧压，左右不对称 | 倾斜而非高度，是"忧虑"的读法 |
| 嘴 | 平直 | 嘴角下压 3 mm、唇线缩短 | 只压嘴角，不整口下移（否则成嘟嘴） |
| 下颌 | 下颌/颅宽 0.72 | 收窄 9%，面颊略平 | 女性区间 0.62–0.75 |
| 头发 | 钟形波波头，前发盖到眉毛 | 前发提到眉上、下摆整体上提 34 mm 并收拢、后颈收边 | 剪影读作短发；侧面能看到耳朵 |
| 拓扑/权重/骨骼 | — | **完全未改**（同顶点数、同顺序、同权重） | 因此可以与烘焙层、动作、清单共存 |

实现位置：`tools/character_geometry.py` 的 `teacher_expression` / `teacher_crop` /
`teacher_eyeball`，由 `tools/prepare_teacher_n.py` 在**烘焙层之后**的后置通道
（`_resting_channel`）执行。之所以必须是后置通道：可见的鼻/睑整形来自
`art/character_models/sculpt/` 的烘焙层，按指纹校验源几何；在后置通道里改形
既不会被它覆盖，也不会让它失效。

验收命令与产物：

```bash
PYTHONPATH=<meshoptimizer 路径> python3 tools/prepare_teacher_n.py --check   # 可复现
python3 tools/model_library.py --check                                        # 结构清单
PYTHONPATH=tools/character_review python3 tools/character_review/anthropometry.py
python3 tools/character_review/contact_sheet.py out.png <before.glb> <after.glb>
```

# Where Is School｜序章剧情与机制补充

> **状态：** 提案／待所有者进一步定稿；不是已实现功能、最终剧本或技术架构决议。
> **来源：** 所有者于 2026-11-21 的口述构想。
> **范围：** 只记录剧情骨架、选项方向、能力关系和人物笔记要求。具体对白、选项措辞、内心独白及文学性荒诞文本由作者撰写。
> **保密边界：** 本文只保留制作所需的简要事实，不复制私人小说《生物课》的段落或独特措辞。

## 1. 与现有序章的关系

现行序章仍以主角在生物课教室醒来、与 Q 交谈、发现课本不在书包里、等待生物老师 B，最终由代课老师 N 接手课堂为基础。B 在真实课堂中缺席，N 负责代课。

本提案增加的是一段由主角主动选择进入的**主观幻想／预演**，不是把幻想改写成真实发生的课堂事件，也不意味着 B 已在现实序章正式登场。玩家可以不进入这段内容，原有主线仍应成立。

## 2. 由 Q 的描述触发对 B 的想象

### 触发入口

- Q 在对话中描述生物老师 B 的外观。
- 主角听到描述后，玩家可以选择是否认真回想／想象 B。
- 选择深入想象，才进入这段主观场景；选择不在意则跳过，不触发该段幻想。
- 玩家进入后仍可在后续节点选择继续深化，或随时意识到这是幻想并退出。

### 幻想场景的基本骨架

1. 主角根据 Q 的描述开始想象 B 的形象。
2. B 在主角的幻想中出现并开始上课。
3. B 点名并要求学生拿出课本。
4. B 发现主角没有带课本，要求主角站起来并解释。
5. 玩家选择如何回应，进入不同的对话和事件分支。
6. 玩家可以继续深入幻想，也可以中途退出，回到现实序章。

以上仅为场景流程，不规定最终台词、镜头或美术实现。

## 3. 回应方向与分支

玩家回应大致分为三类：

- **常规回答：** 采用普通学生可能给出的解释，例如忘带课本。
- **荒诞／幻想式回答：** 以不合常理的方式回应，例如声称课本在 Q 手里，或声称带了课本却忘记放在哪里。此处只记录方向，不代写具体措辞。
- **退出幻想：** 主角意识到这只是想象，主动停止并返回现实。

### 常规回应的可能走向

如果玩家以常规方式回应，B 以教师身份和课堂权威继续施压，可能导致罚站、打手板等惩罚情节。具体事件强度、表现方式和文本仍待作者决定。

### 荒诞回应与「异想天开」

荒诞回应可能进一步分岔，其中一个关键影响因素是新增的独立能力 **「异想天开」**：

- **异想天开较高：** 主角更有能力主导自己的幻想，使 B 被带入主角设定的荒诞情境，或使幻想中的 B 对事件作出不同于常规教师权威逻辑的反应。
- **异想天开较低：** 主角难以主导幻想，B 仍可能以教师权威压倒主角，冲突或惩罚反而升级。

「异想天开」与「洞察」是两项不同能力，不合并、不互相替代。当前只确认其叙事用途；数值范围、判定阈值、检定形式、成长方式及它究竟归入现有内心声音体系还是独立能力栏，均未定稿。

### 荒诞叙事的表现方向

希望通过老师命令与主角实际行动之间的错位产生反讽和荒诞感。例如，老师要求主角站起来，主角却趴下钻到桌子底下；老师要求拿出书包，主角却把书包里的东西全部倒在桌面上。

这些例子仅用于说明动作逻辑上的错位。最终文本、节奏、措辞和文学表达必须由作者自行创作，不由实现者扩写或仿写私人手稿。

## 4. 非线性、交织式剧情结构

- 不采用每个选择都只通向一条独立、纵向剧情线的简单树状结构。
- 采用交织节点：不同选择、回应、能力判定和经历可以彼此影响。
- 多条分支可以在后续节点重新交汇，形成共同结果；共同结果不必具有单一、强烈、直接的因果解释。
- 选择的影响可以体现在后续可说的话、人物反应、主角的理解或可进入的节点，不要求每次选择都永久锁死其他内容。
- 允许玩家随时停止当前幻想；退出幻想本身也是有效选择，不应被视为失败。

具体节点图、状态变量和跨场景后果留待后续设计与试玩验证。

## 5. 能力系统：明确替换与新增

### 已明确的方向

- 将现有设计中的 **「路感」替换为「洞察」**。
- 「路感」原本偏向察觉道路、辨认方向或空间路线，所有者认为这一能力缺乏足够有趣的玩法意义。
- 「洞察」采用更接近传统 RPG 的能力方向，重点不再是寻找道路。
- **「异想天开」作为独立能力新增**，负责影响主角对幻想内容的主导程度；不与「洞察」合并。

### 其他能力

可以继续参考传统 RPG 的能力方向，例如洞察、察觉、敏捷等，同时加入符合本作叙事气质的原创能力。除「路感」替换为「洞察」及新增「异想天开」外，其他能力是否保留、改名或调整，尚未最终确定。

**实现边界：** 本次文档提案不等于运行时代码已经完成改名。现有 `data/abilities/` 中的路感实现需要另行检查调用点、存档兼容和测试，再决定迁移方案。

## 6. 笔记本新增栏目：「刻板印象」

希望在游戏笔记本中新增一个独立栏目，名称为 **「刻板印象」**，用于记录主角接触人物后逐渐形成的主观印象。

- 每个已接触人物可以有一份印象记录。
- 记录的是主角当前对该人物的概括和判断，不等于客观事实。
- 后续经历可以补充、修正甚至推翻既有印象；是否自动变化以及变化规则待定。
- 该栏目与普通事件笔记区分，不把主角的判断写成全知叙述。

### Q：目前已口述的印象

- 坐在主角旁边的胖子。
- 经常主动与主角套近乎。
- 经常挖苦、讽刺主角。
- 性格有些自来熟。
- 带有自作聪明的感觉。

以上只是当前已明确的印象要点，后续可由作者补充、调整。

### 代课老师 N

- 已确定属于该栏目可能收录的人物。
- 具体印象内容尚未提供，留待作者补充。

### 生物老师 B

- 已制作角色模型，但尚未正式接入游戏。
- 本提案通过 Q 对 B 的外观描述触发主角主动想象。
- 对 B 的刻板印象内容尚未提供；不能把幻想中的行为直接当作 B 的客观性格事实。

## 9. 校园霸凌者：逃课路线中的遭遇与分支

### 角色接入状态

- 校园霸凌者的 3D 形象已经由另一个 Agent 制作完成，但目前尚未接入游戏。
- 本提案记录其在序章中的剧情入口、关键选择和分支方向；不涉及模型导入、动画、碰撞或其他技术实现细节。

### 触发入口：离开教室并选择逃课

- 当玩家选择直接逃课、离开教室时，主角来到一楼通往操场的门附近。
- 校园霸凌者堵在这扇门的位置，主动找主角麻烦，形成一次强制遭遇。
- 遭遇时可能只有主角一人，也可能有 Q 跟随。Q 是否跟随取决于此前剧情中双方关系是否达到相应条件。

### Q 是否介入：由熟悉度决定

- 如果 Q 跟随主角，校园霸凌者准备威胁或霸凌主角时，会出现 Q 是否出手帮助的分歧。
- Q 的反应取决于此前玩家如何对待他，以及双方累积的熟悉度／好感度。
- 如果熟悉度高于某个尚未确定的阈值，Q 会帮助主角对抗校园霸凌者。
- 如果熟悉度低于该阈值，Q 可能袖手旁观，甚至直接跑开。
- 熟悉度的具体数值、阈值、增减规则和是否存在其他影响因素尚待设计。此处先记录关系变量对同一遭遇的影响，不将 Q 的帮助设为固定剧情。

### 主角应对校园霸凌者的主要方向

玩家面对校园霸凌者时，目前有四类应对方向：

1. **顺从：** 主角选择顺从对方，校园霸凌者按常规方式继续霸凌。具体行为和后续影响待补充。
2. **动用能力并接受检定：** 主角尝试运用理性等能力与对方周旋。检定成功后，对方可能不再直接霸凌主角，而是转而提出一起打篮球等要求。篮球活动可能附带输赢惩罚，例如以篮球砸向主角头部；具体规则、表现和后果尚待设计。该路线将能力检定与后续篮球情节连接起来。
3. **逃跑：** 主角试图直接逃离，校园霸凌者会追赶主角，并将其逼到场景中的死胡同或死角。抵达该位置后触发新的剧情节点；死角中的具体事件和后续分支尚未设计，暂时留白。
4. **回忆起自己是成年人并选择反击：** 主角想起自己其实是成年人，决定与校园霸凌者动手，并通过能力检定决定结果。检定成功时，主角可以击倒甚至吓跑对方；校园霸凌者随后向主角服软，并可能转而成为主角的小弟。之后两人可能组成一队参加篮球活动，与由两名黑人留学生组成的篮球队对抗，进入新的篮球剧情节点。该篮球段落可利用游戏中已经存在的篮球场场景，但比赛流程、对话和具体玩法仍待作者完善。

### 篮球剧情的复用与待开发内容

- 校园霸凌者的部分分支会引向篮球活动；篮球场场景已经存在，因此可以考虑复用现有场景承载后续剧情。
- 至少有两种不同关系状态下的篮球方向：主角在能力检定成功后接受对方提出的篮球邀约；或主角反击成功后与已经服软的校园霸凌者组成队伍。
- 与两名黑人留学生组成的队伍进行比赛，是后一方向中已提出的对手设定。不得自行扩写其人物背景、性格或对白。
- 篮球比赛的规则、检定、输赢条件、惩罚、对话和场景演出均待后续设计。

### 结构与实现边界

- 这段遭遇属于逃课路线的可选剧情扩展，不应误写成所有玩家都会经历的固定主线。
- 主角是否有 Q 陪同、Q 是否帮助、主角如何回应霸凌者，以及相关能力检定结果，都是可能影响后续节点的状态。
- 四类应对方向是当前口述的主要路线，不代表最终只能形成四条互不相交的线；后续可以根据实际剧情需要设计交织、回流或汇合。
- 死角剧情、篮球活动和具体惩罚均为待设计内容。当前只记录方向，不补写实际对白、文学叙述或未经作者确认的事件。
- 校园霸凌者的 3D 模型虽然已经制作完成，但尚未接入游戏；本设计记录不代表角色或相关玩法已经实现。

# 美术圣经（Art Bible）

> **英文版为项目规范的基准版本。** 中文阅读版对应 [ART_BIBLE.md](ART_BIBLE.md)。修改时必须同步维护两份文件。

## 视觉主张

**一个具有舞台般空旷感、生活着一群心理特征鲜明人物的表现主义世界。**

where-is-school 是一款文学叙事向的 2.5D 探索游戏。它的视觉语言介于表现主义绘画、图像化插画、手绘痕迹、剧场布景，以及经过刻意设计的 3D 游戏空间之间。

整体方向由四个彼此关联的部分构成：

- **人物——表现主义：** 通过姿态、比例、面部结构、色彩和动作，呈现人物的情绪与心理存在感。
- **环境——图像化与手工感：** 空间可以使用鲜明的色块、松散的轮廓线、手绘痕迹、涂鸦式笔触、粗糙纹理和有意简化的几何结构。
- **室外空间——荒诞的剧场式留白：** 尤其在室外，空间可以像简洁的舞台布景：大片天空与地面、孤立的物件、简化的远景，以及等待或迷失的氛围。
- **对话 UI——融合式构图：** 肖像、文本和选项属于同一幅经过设计的叙事画面，而不是彼此分离的标准化面板。

这个世界可以是不完整的、奇异的，或者在视觉上显得粗粝；生活在其中的人则必须具体而鲜活。

## 艺术参考

以下参考主要用于理解艺术原则和氛围：

- **埃贡·席勒（Egon Schiele）：** 修长的人体、独特的身体比例、暴露而不安的姿态，以及富有表现力的线条。
- **爱德华·蒙克（Edvard Munch）：** 情绪化色彩、心理变形，以及人物与周围空间之间的关系。
- **表现主义绘画与素描：** 主观形体、可见的笔触、不完美的轮廓，以及用于表达内在状态的色彩。
- **涂鸦与非学院派绘画：** 直接的笔触、粗糙边缘、不拘一格的能量和个人化的视觉特征。
- **《等待戈多》：** 极简的剧场布景、暴露而空旷的室外环境、孤立的物件，以及由缺席、等待和不确定性产生的荒诞感。
- **《极乐迪斯科》（Disco Elysium）：** 绘画感人物肖像的艺术独立性，以及可探索的游戏空间与高度艺术化人物图像之间的对比。

这些参考用于启发氛围、构图和技法，而不是固定模板。

## 核心原则

1. **表现力优先于解剖学完美。** 只要能传达人物或情绪，就允许有控制的形体变形。
2. **图像清晰度优先于物理模拟。** 先通过形状、线条、色彩和构图建立画面，再考虑材质复杂度。
3. **留白本身就是叙事。** 空旷可以表达等待、孤独、不确定或迷失。
4. **选择性优先于堆砌。** 重要可交互物品必须清晰、易辨；次要环境保持安静。
5. **粗糙必须有意图。** 不规则边缘、可见笔触、不均匀色彩和不准确透视，只要服务于画面，就可以成为有效选择。
6. **玩法空间必须清晰。** 艺术化变形不能遮挡可行走地面、人物、交互目标、出口或即时导航信息。

## 环境美术方向

### 图像化环境语言

环境应当让人感觉它是被绘制、涂抹或作为图像搭建出来的，而不是对现实进行无遗漏的物理还原。

可以使用：

- 大面积、易辨认的色块；
- 手绘或不规则轮廓；
- 松散线条和可见笔触；
- 选择性加入的涂鸦式痕迹；
- 简化的道具与建筑；
- 色彩区域之间粗粝的过渡；
- 有意的透视偏差和不寻常的空间邻接关系。

图像化不等于画面拥挤。不要在每个表面都铺满笔触，也不要让每件道具都拥有相同的细节量。场景必须保留明确的视觉层级。

### 室外空间：剧场式留白

室外空间是建立游戏视觉身份的重要机会。操场、校园空地、道路、路边空隙，以及居民楼之间的空间，都可以按照简洁的剧场布景来组织。

可以把它想象成一个已经搭建好、只等待少数人物和物件进入的空旷舞台：

- 让天空和地面占据画面中很大的面积。
- 使用简单的地平线，或有意呈现人工感的地面与远景边界。
- 允许一棵树、一张长椅、一根路灯、一块标识牌、一段围栏或一栋远处建筑孤立存在。
- 远处建筑可以稀疏、平面化，或像舞台背景。
- 在画面仍然清晰的前提下，允许不寻常的尺度、间距和透视。
- 可以让人物在广阔的空地中显得很小。
- 不要仅仅为了填满画面而添加环境物件。

最终效果应当带有安静的荒诞感：一个仿佛已经准备好迎接某件事情发生、却一直处在等待中的地方。空旷必须是有意的构图，而不是资产尚未完成。

这是一种空间组织原则，不是要把游戏世界变成字面意义上的剧院。幕布、聚光灯、观众席和传统舞台装饰都不是默认元素。

### 室内空间

室内空间可以比室外保留更多功能性细节，但仍然应当具有选择性和图像化特征。一间教室可以通过少量有意义的元素来辨认——桌椅、黑板、窗户、教师区域和少数剧情相关物品——而不需要堆满所有可能出现的教室用品。

走廊、楼梯、门和房间之间可以出现空间矛盾。即使更大尺度的地理关系不可能成立，玩家仍然应当能够理解眼前的局部空间。

### 材质与表面

优先使用简单材质、绘画表面、大面积色彩变化、手工纹理和有选择的粗粝感。照片级 PBR 细节、无处不在的污垢、锈迹、潮湿感和严重风化，不是本项目必须具备的视觉标志。

表面可以干净、朴素、粗糙或高度图像化。具体处理应当由构图和叙事目的决定。

### 教室材质基准——2026-11-12

  每个渲染器只保留一个淡出来源，不叠乘实例和材质的不透明度。相机、指针可见性和轮廓测试必须一起维护。

**边缘与笔触。** 使用已有手绘接缝和不规则色块边界，不扭曲碰撞体，也不把地板边缘抬高。

薄片或硬法线网格出现裂缝时，移除该物体的描边，不用整体加粗补偿。
宽大色块约为 1–3 m 尺度，次要鬃毛笔触为厘米尺度。笔触保持稀疏、固定于表面，并使用 mipmap。
粉笔、破裂窗格、修补三角尺、课程表与自己课桌的标记仍是有意义的细节；不要为了填空而加通用噪点、污垢、伪文字或涂鸦。

**后续地点复用。** 先验证可行走几何与相机。为新地点选择局部冷暖锚点和一两个高彩度焦点；
重要物体／背景之间的明度或色彩度差至少为 0.15，大面的平均色彩度低于 0.20。
把材质*预设*复制到新地点自己的文件夹，只读引用已审查的 Shader，按当地构图绘制纹理色块。

## 人物美术方向

### 人物设计

人物应当具有独立创作感、清晰的心理辨识度和人的存在感，而不是标准化的游戏人形模型。

可以采用：

- 修长或略微不规则的身体比例；
- 不对称的面部结构；
- 有辨识度的轮廓和服装形状；
- 笨拙、紧张、退缩或其他符合人物个性的姿态；
- 富有表现力的手部、肩部、头部角度和身体重心；
- 不寻常但受到控制的色彩关系。

避免过度夸张的可爱卡通比例，也避免传统学院派写实。形体变形应当揭示人物的某些特征，而不是成为装饰。

### 游戏内 3D 人物

3D 模型和对话肖像承担不同职责。

游戏内模型负责让人物存在于可探索的空间中。优先级如下：

1. 可辨认的整体轮廓；
2. 独特的身体比例；
3. 符合人物特征的姿态和动作；
4. 易于辨认的服装形状与色彩身份；
5. 在游戏镜头距离下足以辨认人物的面部结构；
6. 稳定、经济的动画。

面部细节可以保持简化。不要在 2.5D 摄像机无法呈现的几何细节上投入过多精力。

### 对话人物肖像

对话肖像是高优先级的独立 2D 艺术资产，不是 3D 模型截图、放大渲染图，也不是 3D 模型的自动投影。

肖像明确采用表现主义方向，可以使用：

- 清晰、有力度的可见笔触；
- 变形或不对称的面部比例；
- 非自然的肤色与阴影颜色；
- 不均匀的轮廓和粗糙边缘；
- 具有情绪动机的大胆色彩对比；
- 简化或抽象的肖像背景；
- 根据不同人物设计的独立裁切和构图。

肖像必须让人认得出角色，同时传达某种心理状态。它可以比对应的 3D 模型更加变形、细致或直接地表达情绪。

不同人物不应只是同一套肖像模板换上不同面孔。应当根据人物身份，调整姿态、裁切、笔触、色彩和变形程度。

初期先制作少量有意义的状态，而不是大量差异极小的变体。例如：默认、说话、恼怒、不自在、惊讶或退缩。最终表情数量应由实际对话需求决定。

可编辑源文件和运行时导出图片必须分别保存，并保持清晰的组织方式。

## 色彩方向

色彩应当表达情绪和视觉层级，而不是严格遵循物理材质的真实颜色。

- 环境可以使用受控制的中性、低饱和、暖色或意外鲜明的色块。
- 室外构图可以采用大面积天空色和地面色，并保持远景简洁。
- 持续出现的暖色黄昏可以作为有用的视觉母题，但不要求每个地点都覆盖同一种滤镜。
- 人物肖像可以使用更强烈的对比、不自然的肤色、非现实阴影和带有情绪力量的背景色。
- 可交互物品可以通过选择性的色彩强调提升辨识度。

不要强迫所有场景和人物使用同一套固定配色。应当为不同场景建立局部色彩方案，同时保持整体视觉语言的一致性。

## UI 方向：融合式叙事构图

UI 应当简洁、克制、经过设计，并且易于阅读。对话界面不是把传统角色头像框放在独立文本框旁边。

**人物肖像、对话文本、说话者身份和选项应当共同构成一个融合的画面。**

可以探索以下处理：

- 肖像从屏幕边缘自然进入，或延伸至画面边缘之外；
- 不规则的肖像裁切和轮廓；
- 让肖像色块与对话区域在视觉上产生联系；
- 肖像与文本在构图上相互交错，但不能遮挡阅读；
- 根据人物和情境改变肖像大小与位置；
- 在长篇对话中，为文字调整布局并留出更多空间。

融合不意味着拥挤或混乱。应当保持统一的布局规则和清晰的视觉层级，同时允许有控制的变化。

### 可读性要求

中文长文本是硬性要求。必须保证：

- 舒适的文本宽度与行长；
- 足够的字号和行间距；
- 文字与背景之间有充分对比；
- 对话正文与玩家选项清晰区分；
- 说话者身份容易定位；
- 在支持的分辨率下换行和布局稳定；
- 保留对话记录、文字速度和跳过功能。

当肖像与正文发生竞争时，应当重新调整构图，而不是通过缩小字号或损害阅读体验来解决。

### UI 克制原则

避免不必要的装饰边框、复杂面板、装饰性徽章、过多图标、光泽按钮和厚重渐变。质感应当来自字体、间距、色块、简单线条和受到控制的不规则边缘。

对话记录、物品栏、检查、设置、判定和交互提示等其他界面，也应遵循相同的克制图像语言。

## 摄像机与构图

游戏继续采用受控的 2.5D 摄像机和 3D 环境。

- 保持导航、交互目标和空间关系清晰。
- 使用不对称构图、大面积留白、简化纵深和有意识的色彩分组。
- 在室外场景中，让空旷空间的尺度与玩家的小身影形成对比。
- 通过不可能的连接、尺度变化、重复和空间断裂来产生超现实感。
- 不要为了视觉变形牺牲可游玩空间的清晰度。

## 制作流程

### 环境

1. 首先确定灰盒场景、可行走路线、碰撞和摄像机。
2. 找出少量重要的交互物件和叙事物件。
3. 在添加道具之前，先通过地面、天空、远景和留白确定构图。
4. 建立主要形状和色块。
5. 加入经过选择的手绘痕迹、涂鸦式笔触和表面纹理。
6. 简化或弱化次要物品。
7. 使用实际游戏摄像机检查画面，并确认导航清晰。

### 3D 人物

1. 明确人物的叙事功能和个性。
2. 设计独特轮廓、比例和姿态。
3. 制作经济、易维护的 3D 模型。
4. 建立服装和色彩身份。
5. 只添加在游戏距离下能够看见且有用的面部细节。
6. 在实际场景中测试比例、动画和辨识度。

### 2D 对话肖像

1. 明确已经确认的人物视觉信息，以及仍未确定的部分。
2. 探索少量表现主义肖像方向。
3. 独立于 3D 模型，设计面部、裁切、姿态、配色和笔触。
4. 先完成主要肖像，再制作大量表情变体。
5. 将肖像放入包含真实中文长文本的对话构图中测试。
6. 保留可编辑源文件，并记录资产来源。

### UI

1. 建立肖像、正文和选项融合的对话构图。
2. 使用中文长文本测试，而不是只用占位短句。
3. 测试不同轮廓的肖像和不同人物身份。
4. 验证键盘、鼠标、对话记录、选项和语言切换行为。
5. 测试支持的分辨率和安全区域。

- 引擎：Godot 4.7.2 Stable 标准版。
- 3D 源文件：Blender。
- 运行时 3D 交换格式：优先使用 glTF 2.0 / GLB，除非有记录在案的其他需求。
- 对话肖像：独立的 2D 资产，并保留可编辑源文件。
- 源文件与优化后的运行时导出文件分开管理。
- 在 docs/ASSET_PROVENANCE.md 中记录创作者/工具、来源、许可证、适用条款，以及人工编辑和审批过程。
- 生成或下载的资产不自动获得商业使用或仓库收录许可。
- 必须在真实 Godot 场景中测试资产，不能只在制作软件中验收。
- 渲染与资产复杂度必须符合项目性能预算。

## 视觉验收清单

**环境**
- 是否具有清晰的图像化和手工绘制语言？
- 场景是否经过构图，而不是杂乱堆砌？
- 重要交互物品是否容易辨认？
- 室外场景是否在适当位置通过留白产生舞台布景式的荒诞感或等待感？
- 玩家是否仍然能够理解可游玩的空间？

**3D 人物**
- 轮廓是否具有辨识度？
- 比例和姿态是否表达人物特征？
- 在实际游戏镜头下是否容易辨认？

**对话肖像**
- 是否明确是一件独立的表现主义作品？
- 是否传达了具体的心理存在感？
- 是否能够辨认出角色？
- 是否拥有自身的构图与笔触，而不是模型渲染图？

**对话 UI**
- 肖像、正文和选项是否构成同一个画面？
- 中文长文本是否易于阅读？
- 布局是否在允许变化的同时保持简洁和统一？

## 最终原则

**这个世界可以是不完整的，但生活在其中的人必须是鲜活的。**

室外空间可以近乎空无，却依然具有强烈的存在感。一棵树、一张长椅、一段围栏或一栋远处建筑，就可能为场景提供全部所需的结构。人物可以具有笨拙的比例、明显变形的面孔和粗粝的笔触，但不应因此变成卡通。

where-is-school 的视觉身份来自三者之间的张力：一个具有表现力和图像感的世界、一座暴露在空旷之中的荒诞舞台，以及那些面孔和姿态比周围空间承载更多情绪的人。


## 当前对话界面（已实现的基线）

当前运行版本的对话阅读界面已在 PR #29 中重新设计并经过测试，并于 2026-11-12 随首批确认的人物肖像重新设计了样式。本节记录的是现阶段已经存在的实现，是后续设计的制作基线，不取代上文确定的融合式肖像方向。

- 对话以文字为主，呈现在画面左下方的区域，并沿上边缘向场景自然淡出。界面根据当前内容计算尺寸，同时保留环境画面。
- **阅读语气（所有者 2026-11-12 的方向：“像 Disco Elysium 的对话框”）。** 文字区底色为接近不透明的深色墨色。对话正文、说话者姓名、标题和玩家选项使用衬线字体 Noto Serif SC（`assets/fonts/NotoSerifSC-Regular.otf`），以暖白色排在深色底上。界面的其余部分仍使用 Noto Sans SC。
- 对话正文是视觉上最大的元素：标准字号下为 25 px（原为 22 px），具有经过控制的行长和较宽松的行间距。不允许为了放下文字而缩小字号。
- 说话者姓名承担构图锚点的作用，以加宽字距的大写字母和人物强调色呈现；身份/角色说明保持较小、较低调。
- 叙事来源（亲眼观察、他人转述、回忆或想象）通过克制的细线和小型标签表达，不使用徽章、胶囊标签或高饱和色块。
- 玩家选项以编号文字行的方式呈现在分隔线下方，使用暖朱红色；鼠标指向或手柄光标选中时变为浅杏色，并显示一条细的边缘标记。避免实心按钮、装饰性图标和发光效果。
- **人物肖像。** 主角、Q 和 N 已有经过确认的绘画肖像（`assets/ui/portraits/`，源文件在 `art/portraits/`）。肖像立在屏幕底边，统一从右侧进入，这样在说话者交替时文字区不会左右移动。肖像朝向画面的两条边（上边和朝向文字的一侧）溶入场景，贴着屏幕边缘的一侧保持硬边。不加框、描边或发光。肖像不会压住任何文字或选项，不接收点击，也不会让文字区变窄。B 和内心声音没有肖像，也不显示任何替代图像。
- 主角的检视叙述也会显示主角肖像，因为这些台词的说话者就是主角。这是当前行为，不是已确认的决定；详见引入它的 PR。

随着更多肖像加入，继续把阅读界面向本美术圣经所规定的肖像与文本融合构图推进。必须保留当前实现已经验证有效的特征：必要时以文本为优先的层级、中文长文本可读性、响应式尺寸、清晰的玩家选项、键盘/鼠标交互，以及叙事来源区分。

灰盒人物上方的开发名称标签属于调试工具，不是最终游戏 UI，也不应被视为人物肖像系统的一部分。
## 后现代空间语言与视觉多元性

游戏的美术方向现在明确允许不同媒介和风格并置。此前确立的表现主义、图像化、手工感 2.5D 语言仍然是重要的视觉基础，尤其适用于人物身份和普通校园空间的情绪基调；但它不再意味着每个场所都必须使用同一种渲染方法或统一的 3D 风格。

一个场所可以是：
- 完整的 3D 空间，使用经过明确设计的几何结构与材质；
- 2D 插画、绘画、摄影或拼贴构成的空间；
- 由 3D 几何与 2D 平面、剪影、绘画、标签或图像碎片混合而成的空间；
- 玩家移动或互动时，视觉媒介突然发生变化的空间；
- 有意采用粗糙、示意图式、剧场布景、微缩模型、镜面或其他特殊材料逻辑搭建的空间。

不同场所可以拥有截然不同的视觉身份。同一个场所内部，也可以突然有一张 2D 图像侵入 3D 环境、一块平面背景像真正的门一样运作，或者一个熟悉的物件暴露出不可能成立的空间关系。不要为了表面上的统一，强迫这些元素彼此模仿。

**真正统一游戏的是文学气质和体验，而不是技术或表面画风。** 每一次视觉断裂都应当经过作者性设计：它应当服务于迷失、记忆、制度荒诞、空间不可靠，以及日常校园生活与梦境逻辑之间模糊边界等主题。视觉异质性不等于任意堆砌噪声。

### 风格断裂的设计规则

1. **局部规则可以不同。** 每个地点都可以建立自己的配色、渲染技法、尺度、材质逻辑和空间行为。
2. **矛盾本身可以成为设计工具。** 熟悉的校园物件可以通向不可能的空洞、与建筑不相连的地点，或暴露出本不可能容纳在建筑内部的几何结构。
3. **有意识地使用对比。** 突然从 3D 转为 2D、插入摄影图像、粗糙手绘或改变渲染方式，都应具有明确的构图或叙事目的。
4. **交互必须清晰。** 玩家仍然需要理解什么可以检查、打开、穿过或避开。视觉上的模糊可以是有意的，操作反馈不能含糊。
5. **不要解释每一种不可能。** 世界可以直接呈现空间矛盾，而不必给出完整的世界观解释。让玩家遭遇并自行理解。
6. **避免给所有场景套上同一种超现实滤镜。** 不要让每个地点都充满扭曲、噪点、奇怪符号或恐怖效果。普通空间和安静的段落，才能让不可能事件真正产生力量。
7. **保留故事中的人的尺度。** 即使周围空间变得不合理，人物仍然必须具有具体、鲜明的心理特征。

### 作为空间事件的超现实互动

一次互动改变的可以不只是物件状态，也可以是玩家对建筑本身的理解：窗帘后面可能根本没有外墙；一扇门后面可能出现悬浮在教室内部的楼梯。这些事件应当被设计成一种发现，而不是带有大量解释性特效的传统奇幻传送门。

优先考虑克制的转场、明确的构图，以及清晰的变化前后状态。玩家从实际游戏镜头中应当能够看清不可能的物件或开口。任何坠落、穿越或类似传送的过程，都必须有明确的玩家反馈、可靠的落点和安全的恢复机制。

### 场所研究与未来视觉意象

以下是已经获得认可、可以继续探索的创意方向，并不代表这些内容已经实现：

- **生物课教室——被窗帘遮住的窗户：** 两扇窗户中的一扇继续呈现普通的外部景象，例如窗外晾晒的衣服。另一扇窗户被窗帘遮住。玩家选择拉开窗帘后，外面没有正常的景色，也没有建筑外墙，只有一片空无。主角从教室所在的高度坠落，最后抵达操场。揭示过程应当安静、平常，而不是传统意义上的惊吓桥段。
- **生物课教室——不可能的后门：** 前门仍然是正常的出口。打开另一扇后门后，教室内部出现一段悬浮楼梯：楼梯从屋顶/天花板处向下延伸，无任何支撑地悬在教室空间中，经过讲台上方或前方。它应当显得在建筑上完全不可能，而不是一段隐藏了支撑结构的普通楼梯。是否能够攀爬，以及它承担什么叙事功能，可以之后单独决定。
- **镜面爬行管道：** 一段主角可以爬行通过的狭窄管道，内壁全部由镜面构成，产生重复、碎裂或仿佛无穷无尽的人影倒影。反射可以不符合真实光学规律；如果经过设计的视觉错觉更容易实现，也不必强求完整的物理镜面模拟。
- **出现不可能动物的操场：** 熟悉的操场上可以突然出现鳄鱼、狮子等动物。它们的出现应当和建筑异常一样，带有平静、理所当然的荒诞感，而不必自动变成战斗遭遇或恐怖威胁。
- **未来实验室及其他地点：** 每个新场所都可以引入不同的媒介、空间规则或视觉语法。实验室不必看起来像教室；管道、走廊、操场和室内空间都可以拥有各自独立的视觉处理。

这些是不断扩展的意象目录，不是必须一次性实现的清单。新增想法时，应当将其作为独立的场所研究记录，并简要说明它的情绪目的、视觉媒介、互动方式，以及它与周围空间的关系。

### 异质场景的制作与验收原则

- 在概念设计和灰盒阶段就决定场景采用的媒介与空间规则，不要等到传统 3D 场景全部制作完成后才考虑如何加入异常。
- 场景可以混合 Blender/Godot 3D 资产与 2D 纹理、精灵图、平面、手绘插画、摄影图像或合成图像。所有外部或生成资产都必须记录源文件和来源信息。
- 采用能够实现目标画面的最简单技术方案。如果受控的视觉错觉更可靠，就不要为了真实镜面、程序化传送门或复杂几何而过度开发。
- 必须在实际游戏摄像机和交互流程中验证场景，并测试视觉转场、碰撞、坠落落点、移动过程和玩家恢复机制。
- 即使交互结果是不可能的，重要交互物件的可辨识度仍然必须得到保障。
- 不要为了符合新方向而强行翻新所有已有地点。让视觉多元性逐个场所自然出现，只在它真正服务体验时使用。
- 无论采用何种风格，性能、可访问性、资产授权和可维护性仍然是硬性要求。

**更新后的视觉原则：** 世界可以在不同地点改变媒介、尺度和物理规律，但作品仍应当是一段完整的文学体验，因为所有空间共享着疏离、克制和人的脆弱感。

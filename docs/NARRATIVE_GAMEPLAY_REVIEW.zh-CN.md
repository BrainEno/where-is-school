## 先看结论

**最值得加的是“回去有新事可做”，不是“走到新地方又能读一段”。** 现在已经能让走廊路签影响校墙回想，也能让三处观察在操场汇成一次检定。下一步应让结果反过来影响玩家在旧地点的行动：知道该从哪一侧核对、能向谁追问什么、或者主动保留疑问而继续走。这样同一张地图可以承载更多玩法，而不必铺更多场景。

借鉴《极乐迪斯科》的三个设计原则：**内心声音提供带偏见的看法；失败给出另一种处境，而不是一次空响；早先的行动改变后来可说、可做的事。** 不照搬技能数量、经验等级、思维柜界面或任务列表。学校本身的日常程序、物件、人物与空间已经足够特别。**地点为何不一致可以悬而未决；门能不能走、下一步可以怎么查，应该清楚。**

**第一步仍建议「操场交还板 → 消防梯返回走廊 → 从另一侧复查」。** 生物课已经有借书和点名的局部回响；操场这条线已有成败结果和双向出口，却还没有把结果变成旧地点的动作，更适合补上第一条跨地点闭环。不新增地图，不要求骰赢。「两处 01」可替代它，不并做。

**三条已经能用的写法：**

- **具体承诺比好感值好用。** `q_after_bag` 写下 `q_book_pact`，以后在 `n_class` 能提借书约定；`n_roll_response` 的三个回答也会改变 `q_after_dismissal` 的对应段落。反过来，`asked_q_date` 在本基线的运行内容中只找到写入，没有后续消费者。表达性选项可以只在当下成立；凡是有意留给后文的旗标，标出兑现点，不让它们靠数量显得丰富。
- **物件变化能跨场景记住。** [走廊楼层表与路签](../scenes/locations/corridor/directory_tab.gd) 分开读、拨、恢复；[校墙](../data/dialogue/zh-CN/street.json) 只在首看登记摄像头，之后随当前玻璃门/楼梯记号带出回想。路签不是出口钥匙。这个样板已证明选择可以既改变可见物件，又改变另一处的阅读；尚可再加一步「这使我回来时想核对什么」。
- **跨地点核对已存在，不要重造。** 街道返还牌、巷道返还牌与操场交还板的 `seen:*` 共同开放器材棚 `compare_return`；粉笔引导补 `+1`。`pg_return_match` / `pg_return_unclear` 各有不同笔记，本轮未在运行内容或脚本中找到以这两个条目开启下一处动作的消费者。[折返回归](../tests/return_route_test.gd) 有确定种子的两种分支与能离开的断言；不必另造「路线对比」系统。

## 2. 设计建议：先把一个问题做成玩法，再推广

### P0 — 让笔记从存档案变成能用的线索

推荐把一条叙事线写成：**遇到问题 → 找到不同来源 → 决定如何核对或搁置 → 回到旧地点做一件事 → 带走一个新问题。** 同一结构可用于路线、点名、三角尺，但每条都要有具体的人或物，不能换两句文案就当新任务。

- **先并排，不自动推理。** 只试一个「待核对」栏：包含短问题、已获得的条目及其来源、一个可执行的下一步。没有证据时不列未见物件和未来情节。比如见到两处 `01` 是观察，对其形成的联想是回想或推测；知道摄像头在那里，不等于知道两个入口的关系。没有把握时可以留空，不弹出「完成」或真相判定。
- **把三种状态分开。** ① 门是否可通、路签在哪边，是世界状态；② 玩家读了什么、谁说过什么，是知识；③ 主角暂时信什么、愿意怎么试，是解释/选择。从 ② 派生待核对的问题，用 ① 判断眼下可做的动作；③ 只有要兑现的选择才需要记。不能从一条回想直接写开门旗标，也不要把某个角色的说法改标成观察。
- **让结果有去处。** 一条支路至少兑现一种玩家看得见的变化：回访换一个可检查的部位、可用已有话题去问人，或原来的动作有不同反馈。可先试「明确物件与行动」而非「三条平行剧情线」。无材料、犹豫、跳过都能正常离开；拿全只是改变核对方式，不是通关清单。

**怎么做「会失准的路线笔记」：让建议过期，不让记录撒谎。** 同一页分清两件事：「当时依据」保留条目 ID、说话人及来源；「这次怎么查」只写当前可以执行的动作。亲眼见到牌子是一条观察；牌子指的方向仍是待核对的信息。Q 的说法也不是最新路网。若未来一次明确的场景变化使某条建议待核对，旧条目不改字、不换标签；现场取得了新事实，才以另一条观察并置。没有复查就不写「这次证实」，发现冲突也不自动判其中一方撒谎。第一段只测一个问题下的新旧材料和复查反馈，**不做随时间衰减的地图、路径置信度数值或日志全局模拟**。

### P1 — 用具体关系和不同视角增加密度

**写人物怎么回应，而不是写他们有多喜欢玩家。** 点名是现成模板：自己应名、问 Q 先前发生了什么、保持沉默，后续 `q_after_dismissal` 会给不同回应。将来只为具体的到场、亲历、被告知或承诺写状态，优先在原有会话里加一个可略过的回应，不为每种态度复制整场。Q 可以忙、记错或不在；其不在时仍可自行观察，跟随仍是独立的移动状态。第 3 节给出两种可选的局部续写，不需要把开场重做一遍。

**让第二个声音和路感看见同一件事的不同面。** 六个声音是[作者确认的方向](NARRATIVE_BIBLE.md#inner-voices)，不必同时实现六个。若先做空间核对，可试 **细察**（帮玩家找可触摸、可回头验证的差别）；若先做物件记忆，可试 **回声**（带出可疑的旧印象，不认定它发生过）。第一轮只在一个现有节拍里试两种读法；让它们带给玩家不同的行动，而不只是两段解释。

| 声音 | 可带出的玩法（未定稿） | 盲区也应被写出来 |
|---|---|---|
| 路感 | 换一侧看门槛，回走一段，用空间对照 | 两边站位对得上，不等于知道权属或历史 |
| 细察 | 看磨损、对比字样，提出一个能验证的小问题 | 细节是真的，结论仍可能过度 |
| 回声 | 旧物引出一段片段，挑一处回来验证 | 熟悉感不是发生过的凭证 |
| 臆想 | 提供一种可能情境，随后由玩家选是否追索 | 想象序列不改世界、不开门、不写实际检定 |
| 推演 | 用互相冲突的线索提出两种解释，指出缺的那一块 | 解释自洽不代表前提可靠 |
| 共鸣 | 从同一场交谈里提出两种问法，或建议先不追问 | 可解释停顿，不能读取他人的真实动机 |

一个人刚说完，通常比立刻来两条旁白更需要留白。初期优先在**同一个短会话**里有作者编排的回应；不要为了表现争论扩大被动队列。同一触发碰上多个声音，应明确主次、后者不白耗次数、无声音时主线照样走。扩充到达触发前，补一条时序用例：`LocationHost.location_entered` 先于 `LocationFlow` 提交抵达旗标，而 `InnerVoiceDirector.request()` 入队时就会查 `requires`。如果以后某规则依赖本次抵达刚写的旗标，会有入队失败的风险；当前三条规则不依赖它，不把风险写成已复现故障。区分真正跨门、读档重建、对话切语，不把同一事件消费两次。

### P1 — 检定回答「怎么试」，失败也给下一手

- **直接能看到的，不掷骰。** 玩家走近、对着图形或两端查看，就得到观察。**隐检**决定声音指出哪一处，或者是否沉默；不藏唯一线索。**显检**用于玩家主动选择、且有风险或代价的尝试，比如当场追问、伸身试探、和某人一起对照。掷骰前能理解试的是什么，结果后的代价要落到场景或人物上；不能只换红绿字。
- 保留一套 `CheckResolver`。现在 `2d6 + 3` 对难度 10 的理论成功率是 `21/36 ≈ 58%`；同一例加 1 是 `26/36 ≈ 72%`。一条来自调查的加值已经明显改变结果，先让玩家看懂它从何而来，别叠数层加成。公式与难度仍是 [ADR 0003](adr/0003-inner-abilities-and-checks.md) 的试验参数，不当作定案。
- **失败可以推进而不能被免费擦掉。** 已有 `check:<conversation>:<node>` 回放原结果；`repeatable` 也不会换这颗骰。以后若确实需要「有了新办法可以再试」，先写成一个独立的新动作或不掷骰的现场补证，保留前一次结果及来源，两者都可解释。同档同准备下，切场、重复交谈、切语和读档都不应改变结果。

### P2 — 让想法慢慢形成，再考虑更长的时间与空间

- **先试一种可修正的倾向。** 例如主角在两个不同事件里选择先复核，再等到一次相反例子；随后出现一条新的追问或一次对声部意见的响应。只统计不同的已完成事件，不按点击次数长经验；切语、重复台词与同一物件重复互动不计。先测「玩家能从后续表现说出自己为什么倾向这么做」，再谈强度、数值、多个思维槽。倾向影响看法或行动方式，不决定真相；A/B/C 的具体内容仍未定，D 仍是延后而非永久排他路线。
- **让课间有几个可辨认的时刻，而非倒计时逼读。** 若以后需要前后变化，先用明确、可推迟的故事节拍（如做完一次往返、选择鸣铃后才行动），只改一两处人物或物件的呈现；等待、阅读、菜单和反复进房本身不该使玩家在自由探索中被卡住。开场现有的书包提醒和等候回退不在这次改造范围。
- **章节可变，章节内可收束。** 让玩家跳过可选段落后仍能走公共出口；不同路径可在同一节拍会合，用局部插入的反应让前因留下痕迹。不要把每个声部、关系和路线作笛卡尔积。扩到多个章节之后，如果路由表及两语结构确实成为反复冲突的来源，再评估以一个结构源生成双语产物；先保留现有加载与导出边界。

**先让玩家认得路，再试改变路。** 第 4 节先验证一次**没换版**的复查：同一扇门，两种接近方式。玩家能不看任务箭头说出「刚才是从哪里来的」，才考虑挑一处旧门槛试装置。学校的识别不只靠同款模型：保留可复认的地标，也可保留同一件手续（如器材交还）；变的是它所在的连接或办理位置。装置可重复作为触发写法，但按钮不必都传送，也不必落在同一类房间。

| 时刻 | 单处换版试验的最小规则（未实现） |
|---|---|
| 操作前 | 玩家至少走过一次普通路线，能认出固定参照，有不操作就能走的路。提示说清能做什么，不预告未知成因。 |
| 操作后 | 只改一个可验证的空间关系，例如熟悉的平台门接向同一学校的另一段。保留一个能认出的地标和一条可返回或绕行的公开路线。让玩家走过去核对；滤镜或台词不能代替可走空间的变化。 |
| 回访与落盘 | 局部触发可参照[教室异常](../scenes/locations/classroom/classroom_anomalies.gd)和 `StagedInteractable`，不复制它的演出。换房仍由 `LocationFlow` / `LocationHost` 校验场景、身份和出生点，成功后才提交抵达状态并按现有边界存档。旧档按未触发解释，拒载留在原处并还控。当前目录按地点 ID 绑定场景；真要用多个可加载版本，先定读档身份与出生点，不让不同几何共用一个模糊的存档目的地。 |
| 验收与延期 | 玩家能指出哪个动作改了哪段路，旧观察仍可读，新观察另记（不要复用同一个去重 ID）。不做随机拓扑或让 UI 假装失灵。先用一个局部试验站住脚，再谈椭圆形建筑；其作用始终是连接学校的版本，不是解释异常或通往任意场景。 |

## 3. 把这套玩法接回生物课开场

**开场要教的是查东西、听不同说法、选择是否介入，不是解释主角为何返校。** 第一遍按可操作的当下展开，不给整节课贴「闪回」标签。下表以[开场编排](../scripts/world/opening_sequence.gd)和[现行对白数据](../data/dialogue/zh-CN/prologue.json)为锚；这里是 P1 候选，不与第 4 节并行立项。

| 节拍 | 已有依据 | 写作与交互边界 |
|---|---|---|
| **醒来 → Q 先开口** | `q_wake` 能说不记得 Q、问时间或沉默，最终给查包目标；`q_claims_blank_exam` 是 `reported`，没认定真的交过白卷。 | 先让熟悉感不对称：Q 可以熟到令人不耐烦，也能提供帮助。作者设定的「最后学期」适合从闲谈或课务中带出，不做解释身份的字幕。问、听、暂不答都回到查包，不让人认领往事才还控。 |
| **查包 / 先不查** | 查包可写 `textbook_missing`；没查有 `BAG_WAIT_EXPIRED`，可跳过 `expected_b`，不写缺书笔记。 | 「没查」不是「没书」，约好合看也不是已获得道具。紧张来自教室里的人和铃声，不加新的读秒、判罚或借书搜集任务。 |
| **三角尺 → 预演** | 尺的观察、Q 的转述、独立的 `recall` 与 `expected_b` 已分开。`expected_b` 的 B 台词是 `imagined`，其中有 `recalled` 插段。 | 用可重看的物件和站位承载压力，不靠旁白断言真的罚过人。可以表达顺从、回避或顶嘴，但预演不写现实里的好恶、检定或门控。 |
| **N 代课 → 留或走** | N 的入场和点名是当下事件；`n_class` 写普通前门所需的 `class_dismissed`。玩家之后仍能改变留／走打算。 | **同一扇门，不同的前因。** 文学参考中的「预想被赶」与实际「获准离开」可以形成反差；不为前一种新增实际事件。不同答法在课间会合，只留下局部回应。让教室外先有一点松弛的步行和观察，再出现不对劲；不因出门立刻追逐、弹异常提示或要求回想。 |

### 值得试的局部回响（两选一）

- **借看：把口头承诺变成能感觉到的协作。** 已有 `q_book_pact` 与 `textbook_missing` 共同开放 `n_class/share_with_q`，另有质疑 Q 后在 N 面前的防备回应。若这一段需加一拍，只在玩家实际选合看、且 N 同意后给一个可见反馈，例如 Q 把书推到两人之间；玩家仍自己决定怎样应名。没查、没约或没开口，正常进行点名。这里的小代价是当众开口、让同桌也被看见，不是少一点资源。验收的是玩家能分辨「Q 答应了」与「此刻真能一起看」，不是为借一本书新增库存或好感值。
- **白卷／点名：把「谁说得对」改成「谁见到了哪一段」。** 「白卷」也可能只是别人对缺考的叫法，不给旧考试追加定案。现在玩家亲自应名后再找 Q，`q_after_dismissal` 已会交代他如何传出缺考的说法；问 Q 与沉默也各有回应，不再写一轮同义追问。更值得试的是**课后自愿回看今天的补记**：若名单和改动在镜头下可读，让 `n_roll_response` 决定本次能核对的注记，不推断旧勾来历或旧考试结果；若只能问在场的 N，记录仍是 `reported`。这里 Q 在意怎样帮同学、是否被当众追问，N 能处理当前这张表，B 的权威先存在于转述和预演里，日后实见另写。不是三个人各掌握一块等着拼完的真相。

**D 怎么玩、怎么验：** 可以查包、应名、离开，也可以遇到不由自己控制的联想；只是不必主动认领或追查往事。`denied_exam_memory` 是一处答法，`BAG_WAIT_EXPIRED` 是开场回退，两者都不当作 D 的分支锁。后续只试一个已见物件或一位在场人物重新打开话题；延后的人可以当场略过、同档再问，先走的人不会损失课间或公共出口。A/B/C 的具体记忆题材不在此决定。

**对话与探索怎样交接：** 长段落可以有闲话、停顿和不改变状态的选项；需要追问时让玩家知道可以去看哪个物件或找谁，听完再把身体和镜头还给玩家。小区已有 `animal_sighting` 的靠近／留在原处，`animal_bill_seen` 是观察，`animal_recall` 是回想。把「多看到一个细节」当作收益即可；再次交互不必给物种答案，也不以此挡路。

**验收锚点：** [双语开场对白用例](../tests/prologue_dialogue_paths_test.gd) 已覆盖借看、质疑、沉默、不同查物顺序与写盘后不重演；[开场续接](../tests/opening_resume_test.gd) 与[主观隔离](../tests/subjective_isolation_test.gd) 可作回归入口。若选做以上一拍，人工各走一次「查包、合看」和「不查、等到 N」，问玩家 N 实际允许了什么、Q 知道什么、接下来能不能不查就走。若新增了延后再追问，用同一档验先离开、后主动回来：未问前不提前给这次追问的笔记，也不改变可走的门。

## 4. 第一段建议做什么：从消防梯的另一侧再看

**切片问题（不是台词）：** 交还板上的方向，经过防火门以后还能怎样验证？玩家应能指出一件当场看见的事，也能说出哪部分器材印记仍解释不了。

**固定参照已在场景里：** [消防梯底的平台和防火门](CORRIDOR_ART.md#walkable-section)有对应的两面：操场一侧有拉手，教学楼一侧有推杆。保留 `pg_to_corridor → FromSchoolyard` 和反向出口 `to_schoolyard`，不换版。复查看的是现有空间和门件，不假设门上另有印记。

| 玩家经历 | 保持现状 | 建议只增加这一点 |
|---|---|---|
| 从走廊直接去操场，没走过街/巷 | 交还板可读，防火门和巷道出口不靠检定开锁。 | 读板才给可忽略的复查提示，提示只引用牌上已知方向；没读也能走，不自动记调查。 |
| 先看三处材料，再到棚边 | 用原 `compare_return`、`ps_return_check`、粉笔加值和「离开」。 | 只将看过的材料与结果放到同一问题下，不新增汇集旗标。 |
| 检定成功，再走防火门 | 保留 `pg_return_match`：棚里的印记经反向对读能与街边的对上。 | 在教学楼这侧**上几级消防梯再回看**，核对门口、楼梯和操场的相对位置。新观察说清如何折返，不把印记相同当成两条路历史相同。 |
| 检定失败，再走防火门 | 保留 `pg_return_unclear`：第二道是长孔还是折痕仍不清楚。 | **从内侧近看推杆，找到往回走的入口。** 只看就记门件；实际折返才能证实两头都能走。仍不替印记补答案。少知道一件事，不少一个可玩的动作。 |
| 跳过比较，或不想复查 | 没掷就没有成败，两边照常通行。 | 读过板的人能做不带判断的普通看看，也可径直走开；不把未比较者合进失败分支。到场和走过门不等于已主动复查。 |
| 复查后再来 | 保留原路、当前目标和旧记录。 | 新观察只记一次，此后给短读；不重演、不再掷、不替玩家再选出口。 |

**首轮预算：** 只在两个现有地点增加内容，一个问题、一个复查点、成功／失败的两种反馈加未比较时的普通反馈。不另加人物回应和声音。现场先确认站位和镜头确实看得到门或台阶；看不清就缩小核对范围，不用文案假装玩家看到了。观察锚点不能抢走门的点击/E 激活或手柄焦点；复查可立即退出。

**复用与持久化：** 用 `NarrativeState.has_entry()` 读 `saw_pg_return_board`、`pg_return_match`、`pg_return_unclear`，复用 `JournalCatalog`/`JournalPage` 的切语和来源呈现；引用按 ID，不按翻译文字。复查用既有 `Interactable`，真要协调镜头/姿态才用 [StagedInteractable](../scripts/interaction/staged_interactable.gd)。对话条件目前不查笔记 ID；先由局部交互读，不把笔记全镜像为旗标，也不新造通用条件。新观察在动作完成后才写，随下一个安全保存点或「保存并退出」落盘；旧档缺新增记录视为未复查，读档不重演。

**替代方案，不是第二个 P0：** 「楼层表 → 校墙 → 走廊复看」。用已经见过的 `saw_double_01` 与 `street_camera` 作依据，从当前路签指向的玻璃入口或楼梯一侧核对一处看得见的 `01`；不拨路签也可普通观察，不再开一处检定。先选这一条或消防梯其中之一。

### 怎样算这段值得推广

**自动化建议**（沿用 [折返回归](../tests/return_route_test.gd)、[笔记](../tests/journal_test.gd)、[存档往返](../tests/save_roundtrip_test.gd) 和 [地点事务](../tests/location_transition_test.gd) 的入口/夹具）：

| 用例 | 必须观察到的区别或不变量 |
|---|---|
| 走短路/走长路；先读板再看牌/反过来 | 已读材料任意顺序都能汇合；少一处可不比较。不显示未取得的线索；提示不超出已见路牌或现场公开的出口。 |
| 同固定种子，缺粉笔/有粉笔；另跑完全不比较 | 失败与成功都有复查，未比较没有掷骰记录或失败措辞，三条路径均能用原出口。 |
| 把不同结果带回走廊、再次返回、换语言 | 刚到不记复查；主动上阶回看与近看门件有不同反馈。复访不重复记笔记；旧依据不被新观察覆盖，切语不改来源、不重掷、不重放动作。 |
| 在安全保存点写盘后重新启动 | 旧档缺新增记录仍可走；已完成档恢复同一处复查状态与笔记，地点、出生点、Q 及原路签不串状态。 |
| 在落盘前打断或目的地拒绝加载 | 按现有检查点语义恢复，不写假的「已到达」或半步完成；留在原场景时总能还控、走原出口。 |

**人工试玩提问**（用真实 Windows 构建和[现有试玩清单](PLAYTEST_CHECKLIST.md)）：不提前告诉玩家攻略，让一位走短路、一位走长路，其中有人失败。问「现在你准备去哪，为什么？」「哪一项你亲眼看见、哪一项只是推测？」「这个结果让你做了什么不同的事？」「如果你不想查了怎么走？」如果玩家只记得要把三条笔记集齐、或觉得失败后只能读档，就先改提示和反馈，不扩写下一张地图。再检查长中文、未读分支、键鼠/手柄与触控焦点；现有字号、回看与已读快进不能因此失效。

## 5. 后续制作怎么不失控

| 顺序 | 交付与完成标准 | 本阶段不做 |
|---|---|---|
| **P0：场景卡 + 单段试做** | 消防梯或两处 01，先选一条。作者审「问题、来源、不同结果、下一步和退出」这张卡；批准后按第 4 节验收。关键是玩家能说出实际做了什么不同的事，而不是答对异常原因。 | 不并做两个切片；不做房间换版、任务树、线索网、技巧点。 |
| **P1：在不同题材复用一次** | 优先从第 3 节选一个借看或点名回响，证明同样的来源区分也能写人物。若实际瓶颈是行动缺少另一种看法，再试一个新声音。同一规则两处真正共用再抽象；用现有加载器先做只读报告：会话/节点 ID → 条件写入与读处 → 来源、可退出路径与存档点。 | 不开放工具的结构写入，不做全局好感、课表调度或四条回忆线。 |
| **P2：小规模变体，再评估扩展** | 玩家能辨认并主动使用普通回返后，再试一处局部换版；倾向成长也先只试一种可修正的看法。按实际内容量重测 `load_report`、换场、长文本与字号，再决定是否需要章节清单或分载。 | 不提前为六声部、椭圆形建筑、整个校园或全部记忆分支铺框架。 |

**内容审查的门槛：** 每份新场景卡回答「谁观察/听说/回想？」「不看会怎样？」「之后在哪儿兑现？」「旧档不知道这件事会怎样？」。已经有图可达性、双语、路由、被动目标及笔记身份检查（如 [content_integrity_test](../tests/content_integrity_test.gd)、[inner_abilities_test](../tests/inner_abilities_test.gd)、[subjective_isolation_test](../tests/subjective_isolation_test.gd)）。随规模增加，优先给**永久不可满足条件、被前置规则遮住的路由、没有可退选项的菜单**加有代表性的状态用例；不能把结构上连通当成这组状态下真能走。`once` 的键是会话 ID 加选项 ID（无节点 ID），扩写时注意同一会话不同选项组不要复用这个键。报告以 ID 和具体差异为主，不用文本长度或关键词替代人工审稿；既有候选台词另见 [作者审查 #269](https://github.com/BrainEno/where-is-school/issues/269)。

**扩写前值得补的一个切语用例（静态发现，未实测）：** 在三角尺的首读观察上切 `en → zh-CN`，再推进到排队中的回想。[DialogueController](../scripts/dialogue/dialogue_controller.gd) 在打开检视时已把回想文本放进 `_queue`，而 `_refresh_inspection_text()` 只重绘正在显示的那一行，排队文本可能仍是英文。[现有切语用例](../tests/language_switch_test.gd) 在回想已经进入历史后换语，不覆盖这一拍。要扩写多段检视，先确认这条路径，要求回想按当前语言显示且只记录一次，来源仍是 `recalled`。

**一处已核对的文档偏差：** [内容编辑指南](../data/dialogue_schema/README.md) 的检视章节表仍少实验室，并写成手动登记 `InspectionLibrary.CHAPTERS`；[现行加载器](../scripts/narrative/inspection_library.gd) 已按 `LocationCatalog` 派生。后续加地点时以目录与实际校验为准，不另造清单。对话章节仍用 `DialogueLibrary.CHAPTERS`；两者不是一回事。本评审不覆盖改写现行指南。

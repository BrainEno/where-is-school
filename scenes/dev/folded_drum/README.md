# 折纸圆厅 · 开发场景

用 `project.godot` 打开游戏，在 Godot 里打开 **`scenes/dev/folded_drum/preview.tscn`**，按 **F6** 运行当前场景。

- 按住鼠标左键拖动（或按方向键）环绕，滚轮拉近／拉远。
- **1** 回到参考角度，**2** 看屋顶和背面，**3** 看入口和筒口，**R** 重置。
- 只想摆放模型时，实例化同目录的 `folded_drum.tscn`。模型不带灯光、相机、碰撞、可进入的室内或剧情；预览不接入正式地图，也不随游戏导出。

## 从照片读到的东西

高处的圆厅有深蓝色窗带及卷纸状的圆柱，圆厅之下是凹进去的深色体量；近角的小塔用五段逐层收窄的圆弧和折臂接回圆厅。两翼各自用成排折板盖顶；塔两边分别是暖白框里的密竖条和较暗的竖肋。在较低的位置能看到红白斜条、红口长筒、蓝底的彩色折片和压在青绿底纸上的坡道。筒内壁、楼层边缘、窗格和坡道都是几何，不是贴图。

照片看不到的背面用低调的回廊和窗带闭合；后立面、楼体进深及精确比例都是推定。游戏坐标约为 21 × 14.8 × 20 个单位（宽 × 高 × 深，含底板），不是实测工程尺寸。

## 来源及用途边界

几何、色块和纸纹是针对本项目手工编写的 Godot 形体与着色器源码（Arena 辅助）；用户给的照片只作视觉参考，没有复制像素、导入图片、模型或第三方材质。照片及其中原设计的权利未经核实：本版只作 `dev` 比例研究，**未确认可商用，不应直接用于正式导出**。模型与取景源码都在本目录，参考照片及渲染图不进 Git。

## 复核与截图

使用项目 `.godot-version` 指定的版本，从仓库根目录运行：

```sh
godot --headless --path . --import
godot --headless --path . --script res://scenes/dev/folded_drum/review.gd
# 截图需要窗口；Linux CI 可用 xvfb-run 包裹下面的命令。
godot --path . --resolution 1600x1000 --rendering-method gl_compatibility \
  --audio-driver Dummy --script res://scenes/dev/folded_drum/review.gd -- capture="$(pwd)/build/folded-drum"
```

检查脚本对模型的立体范围、两个空腔、实心口沿和预览输入进行断言；可选的截图模式读取三个实际绘制的窗口画面，不做构图或色彩后处理。

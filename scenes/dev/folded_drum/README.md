# 折纸圆厅 · 开发场景

用 `project.godot` 打开游戏，在 Godot 里打开 **`scenes/dev/folded_drum/preview.tscn`**，按 **F6** 运行当前场景。

- 按住鼠标左键拖动（或按方向键）环绕，滚轮拉近／拉远。
- **1** 是参考角度，**2** 看屋顶和背面，**3** 看金属筒口，**4** 看右侧凹进去的三层百叶，**R** 重置。
- 只想摆放模型时，实例化同目录的 `folded_drum.tscn`。模型不带灯光、相机、碰撞、可进入的室内或剧情；预览不接入正式地图，也不随游戏导出。完整的局部遮蔽效果以项目默认的 Forward+ 渲染器为准。

## 从照片读到的东西

高处的圆厅有深蓝色窗带和卷纸状的短圆柱；近角的小塔用五段逐层收窄的圆弧和折臂接回圆厅。两翼各自用成排折板盖顶；右侧三层竖向百叶各自在一段真实的退后凹槽里，刀片形的竖片和洞壁不是贴在平墙上的线。较低的位置保留红白斜条、蓝底的彩色折片和青绿底纸上的坡道。

左侧两根金属筒的红口环按斜面切出，环的上下缘在筒轴上不齐，斜面以内是实际的空腔。纸浆、砂眼和金属折皱用物体坐标生成；既改变颜色，也扰动表面法线，所以会随光照变化，而不是给截图加一层固定颗粒。主光从左上方打下，右侧的低强度掠射光用于读清百叶的薄边，檐下和接缝保留阴影。

照片没拍到的背面用低调的回廊和窗带闭合；后立面、楼体进深及精确比例都是推定。整体约 21 × 14.8 × 21 个游戏单位（宽 × 高 × 深，含底板与外挑口），不是实测工程尺寸。

## 来源及用途边界

几何、色块和材料纹理是针对本项目手工编写的 Godot 形体与着色器源码（Arena 辅助）；用户给的照片只作视觉参考，没有复制像素、导入图片、模型或第三方材质。照片及其中原设计的权利未经核实：本版只作 `dev` 比例研究，**未确认可商用，不应直接用于正式导出**。模型与取景源码都在本目录，参考照片及渲染图不进 Git。

## 复核与截图

使用项目 `.godot-version` 指定的版本，从仓库根目录运行：

```sh
godot --headless --path . --import
godot --headless --path . --script res://scenes/dev/folded_drum/review.gd
# 截图需要窗口；Linux CI 可用 xvfb-run 包裹下面的命令。
godot --path . --resolution 1280x1440 --rendering-method forward_plus \
  --audio-driver Dummy --script res://scenes/dev/folded_drum/review.gd -- capture="$(pwd)/build/folded-drum"
```

检查脚本验证模型的立体范围、三个百叶凹槽的深度和有效缝隙、两根筒的空腔及管沿的实测斜面，以及预览输入。截图模式读取三个实际绘制的窗口画面，先取竖构图，再切到横构图取两个近景；不另行处理照片或像素。

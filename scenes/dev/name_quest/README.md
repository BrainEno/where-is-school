# 我到底叫什么名字 · 开发试玩

这是**独立的 Godot 开发场景**，不是正式序章的新任务。复用正在使用的教室、N 的放行对话、走廊、Q 跟随及一楼档案室；不改记忆方向或正式场景、台本、角色姓名。放行后，使用教室前门才出现问名。三种回应都开启同一任务，各自保留选择，不为 B 填姓名；不是对主线设计补遗中其他分支的修改。

## 怎么玩

用仓库 `.godot-version` 指定的 Godot 打开项目，打开 [`name_quest.tscn`](name_quest.tscn)，按 **F6**（运行当前场景）。也可从仓库根目录运行：

```sh
godot --path . res://scenes/dev/name_quest/name_quest.tscn
```

1. 从 N 的原有课堂对话开始。等 N 放行、对话结束后，走到前门使用。仍在教室内时，用数字键 **1 / 2 / 3** 或点击选 A／B／C。再次回教室离开不会重问。
2. 在走廊追问同行的 Q；他不在或不想问他时，看公告栏。试玩的字母标记是测试数据，不是正式班号。Q 的转述和公告栏的观察是两条记录。
3. 下楼进档案室，读索引簿。用线索选班级页，左右移动复写件，使两组针孔重合；把座位所在的栏和复写档号对应起来。本场景省去档案门外另一次校准，但不写正式的校准结果。
4. 到室内查验台，选档号、班级、座位都吻合的**正本**。错页、错位、错档都可重试。只有核对完成才显示名字，之后可以重读原件。

完成一段交互并收起卡片后自动存档；关掉再按 **F6**，从上个检查点继续。只使用 `user://name_quest_preview/` 内的存档和阅读记录。常规暂停菜单的正式存档、重开和设置入口在本场景不可用。要从头试另一种回应，请关闭当前窗口后运行（仅重置试玩存档，不会删除正式存档）：

```sh
godot --path . res://scenes/dev/name_quest/name_quest.tscn -- --name-quest-reset
```

当前卡片是简体中文的玩法提示，不是对白。正式游戏的四个导出预设都排除 `scenes/dev/` 和 `scripts/dev/`，此场景也不出现在标题画面。

## 验证

Linux 上在已导入的项目中，用空的临时 Godot 用户目录运行：

```sh
XDG_DATA_HOME="$(mktemp -d)" godot --headless --path . --script res://tests/name_quest_preview_test.gd
```

测试使用真实场景和交互，检查三种门内回应、挂接的 Q 转述、正本核对、失败可重试、中途与完成后的重载，以及正常存档和阅读记录的字节不变。视觉阅读性、实际键鼠／手柄体验仍需在游戏窗口试玩。
